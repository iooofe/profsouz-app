# Профоюз

Проект переведен на архитектуру `Django API + React SPA`:
- `Django` отвечает за бизнес-логику, хранение данных, генерацию Word/Excel и API.
- `React` отвечает за интерфейс (SPA) и работает через API-запросы.

## Особенности

- SPA-интерфейс для вкладок: работники, заявления, отчеты, ведомости, списки
- Session-auth через Django (CSRF защищенные API-запросы)
- Сохранена существующая бизнес-логика заявлений и списков
- Сохранены экспорт/печать документов (Word/Excel)

## Установка и запуск

### 1. Активация виртуального окружения

```bash
source venv/bin/activate
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Применение миграций

```bash
python manage.py migrate
```

### 4. Создание пользователей и импорт работников из Excel файлов

Для создания пользователей и импорта работников из Excel файлов выполните:

```bash
python manage.py create_users
```

Эта команда:
- Найдет все `.xlsx` файлы в папке `работники`
- Создаст пользователей по именам файлов (без расширения `.xlsx`)
- Импортирует всех работников из каждого файла в соответствующий аккаунт
- Автоматически определит структуру данных в файлах

**Важно:** Убедитесь, что папка `работники` существует и содержит Excel файлы с работниками.

**Структура файлов:**
- Название файла (без `.xlsx`) = имя пользователя/аккаунта
- Файл должен содержать таблицу с работниками
- Обязательные столбцы: табельный номер, ФИО
- Поддерживаемые столбцы: ИНН, участок, должность, статус, дата вступления, адрес, телефон

### 5. Создание суперпользователя (опционально, для админ-панели)

```bash
python manage.py createsuperuser
```

### 6. Сборка фронтенда (React)

```bash
cd frontend
npm install
npm run build
cd ..
```

Сборка будет выгружена в `static/spa/`.

### 7. Запуск сервера разработки

```bash
python manage.py runserver
```

После запуска откройте браузер и перейдите по адресу: http://127.0.0.1:8000/
SPA загружается на `/`.

## Вход в систему

Для входа используйте один из предустановленных аккаунтов. Логины и пароли указаны в команде `create_users`.

## Структура проекта

```
profsouz/
├── main/              # Главное приложение
├── profsouz/          # Настройки проекта
├── frontend/          # React SPA (Vite)
├── templates/         # Django шаблоны (в т.ч. shell SPA)
├── static/            # Статические файлы (в т.ч. сборка SPA)
└── manage.py         # Управляющий скрипт Django
```

## Технологии

- Python 3.12+
- CSS3 с поддержкой современных эффектов

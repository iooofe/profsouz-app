# Профоюз

Современная веб-платформа на Django с дизайном в стиле iOS 18.

## Особенности

- 🎨 Современный дизайн в стиле iOS 18
- ✨ Плавные анимации и переходы
- 📱 Адаптивная верстка
- 🚀 Быстрая и оптимизированная работа
- 🔐 Система обязательной аутентификации
- 👥 Предустановленные пользователи

## Установка и запуск

### 1. Активация виртуального окружения

```bash
source venv/bin/activate
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Применение миграций

```bash
python manage.py migrate
```

### 4. Создание пользователей

Для создания всех предустановленных пользователей выполните:

```bash
python manage.py create_users
```

Эта команда создаст 16 пользователей с заранее заданными логинами и паролями.

### 4.5. Импорт работников из файлов (опционально)

Если у вас есть файлы с работниками в папке `работники`, выполните:

```bash
python manage.py import_workers_from_files
```

Команда автоматически обработает все `.docx` файлы в папке и создаст карточки работников.

### 5. Создание суперпользователя (опционально, для админ-панели)

```bash
python manage.py createsuperuser
```

### 6. Запуск сервера разработки

```bash
python manage.py runserver
```

После запуска откройте браузер и перейдите по адресу: http://127.0.0.1:8000/

**Важно:** Все страницы требуют обязательной авторизации. При попытке доступа без входа вы будете перенаправлены на страницу входа.

## Вход в систему

Для входа используйте один из предустановленных аккаунтов. Логины и пароли указаны в команде `create_users`.

## Структура проекта

```
profsouz/
├── main/              # Главное приложение
├── profsouz/          # Настройки проекта
├── templates/         # HTML шаблоны
├── static/           # Статические файлы (CSS, JS)
└── manage.py         # Управляющий скрипт Django
```

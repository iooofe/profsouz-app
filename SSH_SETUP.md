# Настройка SSH подключения к серверу

## Проблема: Permission denied (publickey)

Сервер настроен только на аутентификацию по SSH ключу, а не по паролю.

## Решение 1: Использовать SSH с опцией для пароля (временное решение)

Попробуйте подключиться с явным указанием использования пароля:

```bash
ssh -o PreferredAuthentications=password -o PubkeyAuthentication=no root@your-server-ip
```

Если это не работает, переходите к Решению 2.

## Решение 2: Настроить SSH ключ (Рекомендуется)

### Шаг 1: Создайте SSH ключ (если его нет)

```bash
# Проверьте, есть ли у вас SSH ключ
ls -la ~/.ssh/id_rsa

# Если ключа нет, создайте его:
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
# Нажмите Enter для всех вопросов (используйте значения по умолчанию)
```

### Шаг 2: Скопируйте публичный ключ на сервер

**Вариант А: Через ssh-copy-id (если сервер разрешает пароли временно)**
```bash
ssh-copy-id root@your-server-ip
```

**Вариант Б: Вручную (если ssh-copy-id не работает)**

1. Покажите ваш публичный ключ:
```bash
cat ~/.ssh/id_rsa.pub
```

2. Скопируйте вывод команды

3. Подключитесь к серверу через другой способ (веб-консоль хостинга, VNC и т.д.) и выполните:
```bash
mkdir -p ~/.ssh
chmod 700 ~/.ssh
echo "ВАШ_ПУБЛИЧНЫЙ_КЛЮЧ_ЗДЕСЬ" >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
```

## Решение 3: Включить вход по паролю на сервере (Временное решение)

Если у вас есть доступ к серверу через веб-консоль или другой способ:

1. Подключитесь к серверу любым доступным способом

2. Отредактируйте конфигурацию SSH:
```bash
nano /etc/ssh/sshd_config
```

3. Найдите и измените строки:
```
PasswordAuthentication yes
PubkeyAuthentication yes
```

4. Перезапустите SSH сервис:
```bash
systemctl restart sshd
```

5. Теперь вы сможете подключиться по паролю:
```bash
ssh root@your-server-ip
# Введите пароль: ваш_пароль
```

**⚠️ ВАЖНО:** После успешного подключения и настройки SSH ключа, рекомендуется снова отключить вход по паролю для безопасности:
```
PasswordAuthentication no
```

## Решение 4: Использовать веб-консоль хостинга

Если у вашего хостинг-провайдера есть веб-консоль (например, через панель управления), вы можете:

1. Войти через веб-консоль
2. Выполнить команды развертывания напрямую там
3. Или настроить SSH ключ через веб-интерфейс

## После настройки SSH

Как только вы сможете подключиться к серверу, выполните:

```bash
ssh root@your-server-ip

# Затем выполните команду развертывания:
bash <(curl -s https://raw.githubusercontent.com/iooofe/profsouz/main/deploy_full.sh)
```

## Важные замечания

### Переменные окружения для деплоя

Перед запуском скриптов деплоя на сервере установите:

```bash
export GITHUB_TOKEN="your_github_token_here"
```

### Файлы, которые НЕ должны попасть в репозиторий

Убедитесь, что в `.gitignore` есть:
- `.env` - файлы с секретами
- `db.sqlite3` - локальная база данных
- `venv/` - виртуальное окружение
- `staticfiles/` - собранные статические файлы
- `media/` - загруженные файлы
- `работники/` - папка с Excel файлами (если содержит чувствительные данные)

### Проверка перед коммитом

```bash
# Проверка что нет секретов
grep -r "SECRET_KEY" --exclude-dir=venv --exclude="*.pyc" .
grep -r "github_pat" --exclude-dir=venv --exclude="*.pyc" .

# Проверка что .env в .gitignore
grep -q "^\.env$" .gitignore && echo "✅ .env в .gitignore" || echo "❌ .env НЕ в .gitignore"
```

## После деплоя на сервере

1. Убедитесь, что папка `работники` с Excel файлами скопирована на сервер
2. Запустите команду создания пользователей:
   ```bash
   python manage.py create_users
   ```
3. Проверьте, что все работники импортированы корректно

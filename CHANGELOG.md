# Changelog

## [Unreleased]

### Added
- Команда `create_users` теперь работает с Excel файлами (.xlsx) вместо Word
- Автоматическое определение структуры данных в Excel файлах
- Поддержка файлов с разными структурами заголовков
- Автоматическая синхронизация работников при деплое
- Systemd service для автоматической синхронизации при старте системы
- Улучшенная обработка табельных номеров (сохранение полной точности для больших чисел)

### Changed
- Команда `create_users` теперь импортирует работников из Excel файлов автоматически
- Название файла Excel = имя пользователя/аккаунта
- Убраны GitHub токены из скриптов деплоя (теперь используются переменные окружения)

### Fixed
- Исправлена обработка табельных номеров (большие числа теперь сохраняются полностью)
- Исправлена обработка файлов без явных заголовков
- Исправлена обработка заголовков, разбитых на несколько строк
- Исправлена проблема с чтением табельных номеров из разных колонок

### Security
- Удалены хардкоженные GitHub токены из скриптов деплоя
- Токены теперь используются через переменные окружения
